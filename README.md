# NovaRescue
NovaRescue — инновационный стартап, объединяющий безопасность и современные технологии. Проект разрабатывает интеллектуальных роботов для доставки грузов, работы в опасных зонах и оказания помощи при чрезвычайных ситуациях. Решение направлено на снижение рисков для людей, повышение эффективности спасательных операций
