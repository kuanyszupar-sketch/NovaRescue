# NovaRescue — Сайт проекта

Современный интерактивный веб-сайт проекта **NovaRescue** — автономной роботизированной системы городской логистики для Алатау.

## 📁 Файлы

- **index.html** — Основная структура (HTML5)
- **style.css** — Стили и дизайн (CSS3 с анимациями)
- **script.js** — Функциональность и интерактивность (JavaScript)
- **IMG_3267.jpeg** — Фото основателя
- **IMG_3368.jpeg** — Фото сборки робота
- **4194db97-acfa-4594-b2dd-74d2bf48f1e3.jpeg** — Фото VEX Robot

## 🚀 Быстрый старт

### Локально

1. Скачайте все файлы в одну папку
2. Откройте `index.html` в браузере (Chrome, Firefox, Safari, Edge)

### На сервер

Загрузите все файлы на веб-хостинг (например, Netlify, Vercel, GitHub Pages):
```bash
# Убедитесь, что все файлы в одной папке
ls -la index.html style.css script.js *.jpeg
```

## ✨ Функции

### 🗺 Интерактивная карта
- Живая SVG-карта Алатау с пинами локаций
- Склад, кафе, административные здания, пункты выдачи
- Маршрут робота под ЛРТ
- Легенда с цветовым кодированием

### 📦 Оформление заказа
- Выбор источника (кафе, магазины, аптеки)
- Выбор пункта выдачи
- Генерация трек-номера
- Штрихкод для посылки
- Поиск ближайшего пункта по геолокации

### 📍 Отслеживание
- Ввод трек-номера
- Визуальная временная шкала доставки (timeline)
- 4 этапа доставки

### 🌍 Мультиязычность
- **Қазақша** (Казахский)
- **Русский**
- **English** (Английский)

Переключатель языков в правом верхнем углу (KZ / RU / EN).

### ✅ Анимации
- Scroll-reveal для секций (плавное появление при скролле)
- Hover-эффекты на карточках (lift & shadow)
- Робот движется по маршруту на карте
- Плавные переходы

## 📱 Адаптивность
